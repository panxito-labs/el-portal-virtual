# 🌈 EL PORTAL EN LA REALIDAD VIRTUAL 🌈

¡Bienvenidos al portal en la realidad virtual! Una página personal estilo **GeoCities 1999** hecha con amor, antorchas animadas, `<marquee>`, Comic Sans y un contador de visitas que sí funciona.

## 🔥 Características

- Letras arcoíris con antorchas animadas 🔥
- Marquee de bienvenida
- Video de YouTube embebido
- Secciones: Fotos nuestras, En la prensa, Mi carnet, Yo de niño, Nuestros memes
- WebRing falso estilo 2001
- Libro de visitas con mensajes de 1999
- Contador de visitas funcional
- Música de ambiente
- Requisitos: Chispoqueso Explorer 5.1, gafas anaglifo 3D y soporte MIDI

## 🚀 Cómo verla

Abre `index.html` en tu navegador, o publica este repo con **GitHub Pages**:

1. Ve a `Settings` → `Pages`
2. En "Source" elige la rama `main` y la carpeta `/ (root)`
3. ¡Tu página estará en `https://panxito-labs.github.io/el-portal-virtual/`!

## 🛠️ Tecnología

- HTML5 + CSS + JavaScript puro
- Sin dependencias, sin build, sin límites (como en 1999)
